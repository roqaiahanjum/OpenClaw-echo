## 2. Environment Prerequisites

- **Operating System:** Windows 10/11, Ubuntu 22.04 LTS+, or macOS.
- **Node.js:** v20.0.0 or higher.
- **TypeScript:** v5.6.3 (`npm install` installs all required packages from `package.json`).
- **Dependencies:** `telegraf`, `sqlite3`, `@langchain/core`, `@langchain/google-genai`, `groq-sdk`, `zod`.

## 3. Step-by-Step Reproduction Instructions

### Step 1: Install Dependencies
From the repository root:
```bash
npm install
```

### Step 2: Execute the Empirical Benchmark Harness
Execute the genuine evaluation runner via `ts-node`:
```bash
npx ts-node scripts/execute_real_experiments.ts
```

### Step 3: Expected Console Execution Output
During execution, the console will output:
1. `[1/4] Running Real Intent Classification Experiment (100 prompts)...`  
   $\to$ Outputs raw accuracy (~81.0%) and Macro-F1 (~81.5%).
2. `[2/4] Running Real Knowledge Graph Retrieval Experiment (50 queries on isolated SQLite DB)...`  
   $\to$ Creates `eval_test_memory.db`, executes BFS queries, and outputs Mean Precision@5 (~68.0%), Recall@5 (100.0%), and mean latency (~0.61 ms).
3. `[3/4] Running Controlled Provider Failover Experiment (50 controlled trials)...`  
   $\to$ Injects 50 simulated fault scenarios into `ModelRouter`, outputs recovery rate (~90.0%) and switchover time (~1.14 ms).
4. `[4/4] Running Multi-Agent Functional Workflow Tests...`  
   $\to$ Executes parallel task dispatch, DAG dependency resolution, AST code security guard, and SSRF URL validator.
5. `✅ All genuine benchmark CSV files successfully generated in research_validation/real_experiments/`
