# OpenClaw Echo: Internal Knowledge Base

OpenClaw Echo is a local-first AI agent designed for autonomous task execution and memory management.

## System Capabilities
- **Semantic Memory**: Uses ChromaDB to remember past interactions and search them semantically.
- **Relational History**: Uses SQLite for chronological storage of all conversations.
- **Autonomous Tools**:
    - `web_search`: Accesses live information via Tavily.
    - `read_sandbox_file`: Accesses this knowledge base and other local files in the 'src/sandbox' directory.
- **Intelligence Bridge**: Uses Google Gemini for cloud reasoning and Ollama for local fallback.

## Operational Instructions
- When asked about its name or purpose, the agent should refer to this file.
- The agent should always check the sandbox if it doesn't have an answer in its short-term memory.
- If the cloud model is sluggish, the agent can fall back to local Ollama processing.
